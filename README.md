# SYNTHESIZER (SynthGame)

###

<h3 align="left"> 📌 О проекте: </h3>
<p align="left"> Проект представляет собой приложение с возможностью подключения MIDI-устройств, разработанное с использованием C# и GDScript. Этот проект был создан в рамках дипломной работы. </p>

###

<h3 align="left"> 💾 Клонирование репозитория: </h3>
<p align="left"> git clone https://github.com/ShDaniCalifornia/SynthGame.git </p>

###

<h3 align="left"> ⚙️ Ключевые особенности: </h3>
<p align="left"> - Возможность подключения MIDI-устройств (см. раздел «Подключение MIDI-устройства»); </p>
<p align="left"> - Регистрация и вход в учётную запись; </p>
<p align="left"> - Прохождение уровней и получение опыта для повышения уровня профиля; </p>
<p align="left"> - Изменение звучания MIDI-устройства путём выбора SoundFont в настройках игры (см. раздел «Установка SoundFont»); </p>
<p align="left"> - Переключение устройств ввода и вывода в настройках игры. </p>

###

<h3 align="left"> 🛠️ Технический стек и зависимости: </h3>

<p align="left"> 1. Godot 4.3 (GDScript). </p>
<p align="left"> - Выступает в роли клиентского уровня и основного управляющего модуля, отвечая за весь пользовательский интерфейс (UI), интерактивную визуализацию клавиатуры, а также игровую и обучающую логику (система уроков, аутентификация, прогресс). Функционирует как хост-среда, взаимодействуя с низкоуровневыми сервисами на C# для обработки аудио и MIDI. </p>
<p align="left"> 2. Visual Studio 2022 (C#). </p>
<p align="left"> - Служит серверной частью, которая с использованием библиотек NAudio и MeltySynth обеспечивает вывод звука, обработку MIDI-ввода и управление пользовательскими данными через Entity Framework Core. </p>
<p align="left"> - Обеспечивает подключение к базе данных и реализацию хранения данных профиля пользователя и прогресса в уроках (SQL Server). </p>
<p align="left"> 3. Библиотеки, используемые в проекте синтезатора: </p>
<p align="left"> - ManagedBass / ManagedBass.Midi (3.1.1) </p>
<p align="left"> - MeltySynth (2.4.1) </p>
<p align="left"> - NAudio (2.2.1) </p>
<p align="left"> - Microsoft.EntityFrameworkCore (8.0.4) </p>

###

<h3 align="left"> 🎹 Подключение MIDI-устройства: </h3>
<p align="left"> Доступно несколько способов подключения в зависимости от типа вашего MIDI-устройства. </p>

<p align="left"> 1. Прямое подключение (MIDI-OUT / USB) </p>
<p align="left"> • Подключите MIDI-контроллер к компьютеру: </p>
<p align="left"> - Через USB-кабель: если на вашей клавиатуре есть USB-выход (обычно «USB Type B»), подключите её напрямую. </p>
<p align="left"> - Через MIDI-USB-адаптер: если на клавиатуре есть только круглые MIDI-OUT порты, используйте соответствующий адаптер. </p>
<p align="left"> • Обычно устройство распознаётся системой автоматически. </p>

<p align="left"> 2. Подключение по Bluetooth (с использованием внешних мостов) </p>
<p align="left"> • Необходимое программное обеспечение: </p>
<p align="left"> - midiLoop (виртуальный MIDI-кабель): устанавливается для создания виртуального порта, который сможет видеть SynthGame; </p>
<p align="left"> - MidiBerry: устанавливается для обнаружения вашего Bluetooth-MIDI-устройства и перенаправления его сигнала на виртуальный порт. </p>

<p align="left"> • Процедура подключения: </p>
<p align="left"> - Запустите midiLoop и создайте виртуальный порт, нажав на значок плюса. Убедитесь, что в списке появился активный виртуальный порт (например, LoopPort). Этот порт будет использоваться в качестве моста; </p>
<p align="left"> - Запустите MidiBerry и в верхней части интерфейса найдите ваше физическое Bluetooth-устройство (например, SMK25V2) в списке доступных устройств; </p>
<p align="left"> - Подключитесь к устройству; </p>
<p align="left"> - В нижней части интерфейса MidiBerry перенаправьте MIDI-выход вашего Bluetooth-устройства на виртуальный порт, созданный midiLoop (например, LoopPort). </p>

<h3 align="left"> 🔉 Установка SoundFont: </h3>

<p align="left"> Для корректной работы синтезатора требуется SoundFont-файл FluidR3_GM.sf2. Он не включён в Git-репозиторий из-за большого размера. </p>

<p align="left"> 1. Скачайте файл по следующей ссылке: https://member.keymusician.com/Member/FluidR3_GM/index.html </p>
<p align="left"> 2. Создайте папку с именем SoundFonts в корневом каталоге проекта. </p>
<p align="left"> 3. Скопируйте загруженный файл FluidR3_GM.sf2 в эту папку. </p>
